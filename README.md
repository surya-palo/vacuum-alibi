One line, at most 200 characters, in which a robot vacuum explains why it
missed a spot — deadpan, surprising, tight, punch at the end.

## Entry

> I did not miss the spot. I scanned it, named it Gerald, and my warranty forbids eating anything with a name.

108 characters. The vacuum doesn't deny the spot: it scanned it, gave it a
name, and now its warranty forbids eating anything with a name. Deadpan
machine voice, one unexpected turn (Gerald), punch at the end.

## Run

```sh
python3 main.py   # writes the line to /output/entry.txt
```

Python standard library only. Deterministic: the same bytes every run.
